# ☕ CemalCemil Coffee - Website Portofolio

Website kafe fiktif yang berlokasi di Lombok, dibangun dengan konsep "Dusty Vintage" yang memadukan nuansa dusty green dan pink pastel. Proyek ini dibuat untuk mendemonstrasikan kemampuan Front-End Web Development.

🌐 **[KLIK DI SINI UNTUK MELIHAT WEBSITE LIVE](https://NadiaIndah20.github.io/cemalcemil-coffee/)**

## 🛠️ Tech Stack
- **HTML5:** Struktur semantik, SEO-friendly meta tags, dan accessibility (alt text).
- **CSS3:** CSS Variables, Flexbox, CSS Grid, dan Media Queries untuk desain responsif (mobile-first).
- **Vanilla JavaScript:** DOM Manipulation untuk mobile menu, Intersection Observer untuk animasi scroll reveal, dan WhatsApp API integration untuk form reservasi.

## ✨ Fitur Utama
- 🎨 **Desain UI/UX Estetik:** Palet warna dusty green & pink yang konsisten dengan branding.
- 📱 **Fully Responsive:** Tampilan optimal di desktop, tablet, dan mobile.
- 📅 **Form Reservasi Fungsional:** Integrasi langsung ke WhatsApp API dengan format pesan otomatis.
- 🖼️ **Galeri & Peta:** Menampilkan foto asli interior/eksterior dan embed Google Maps lokasi Lombok.
- ⚡ **Optimasi Aset:** Penggunaan gambar lokal dan kompresi untuk performa loading yang cepat.
